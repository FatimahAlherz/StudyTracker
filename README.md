# StudyTracker
A simple Java console app that helps student track thir study hours and progress for each subject.

Smart Study Tracker is a simple (Java console program) that helps students track their study progress for each subject

It allows users to enter their subjects, target study hours, and the number of hours they actually studied — then calculates the completion percentage for each subject

 Features
- Add multiple subjects
- Set a target number of study hours for each subject.
- Enter the actual study hours
- Displays a detailed progress report showing the completion percentage

Example Output
Welcome to Smart Study Tracker!

How many subjects do you want to track? 2



Enter subject name #1: Programming

Enter target study hours for Programming: 10



Enter subject name #2: Math

Enter target study hours for Math: 8



How many hours did you study for Programming? 7

How many hours did you study for Math? 4



Study Progress Report:

Programming: 70.0% of goal completed.

Math: 50.0% of goal completed.

Concepts Used
- Java Arrays
- Loops (`for` loop)
- User input using `Scanner`
- Type casting and percentage calculation
- Formatted printing using `printf`
